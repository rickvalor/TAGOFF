# Examples

Every pair below was generated by actually running `clean_url` against the
real shipped `data/` lists — not hand-typed. Regenerate this file after any
change to the lists by running the examples in `scripts/bench.py`'s sibling
script or just pasting these URLs into `tagoff -v`.

**News article shared on social media** (strips UTM, keeps the real share-medium id):
```
IN:  https://www.nytimes.com/2026/10/29/technology/ai-agents.html?utm_source=twitter&utm_medium=social&utm_campaign=fall2026&smid=tw-share
OUT: https://www.nytimes.com/2026/10/29/technology/ai-agents.html?smid=tw-share
removed: utm_source, utm_medium, utm_campaign
```

**Amazon product link** (found as a real gap in round 11 of the critique
ledger — the recommendation-widget tracking went completely untouched on
the first pass; `_encoding=UTF8` is correctly left alone, it's not tracking):
```
IN:  https://www.amazon.com/dp/B08N5WRWNW?ref=sxts_klp_1&_encoding=UTF8&pd_rd_i=B08N5WRWNW&pd_rd_r=abc123&pd_rd_w=xyz&pd_rd_wg=qrs&pf_rd_p=1&pf_rd_r=2
OUT: https://www.amazon.com/dp/B08N5WRWNW?_encoding=UTF8
removed: ref, pd_rd_i, pd_rd_r, pd_rd_w, pd_rd_wg, pf_rd_p, pf_rd_r
```
